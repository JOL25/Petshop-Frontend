# Triopi Petshop Frontend

Frontend de la tienda Triopi Petshop, construido con React, TypeScript y Vite.
Consume la API de
[Petshop Backend](https://github.com/JOL25/Petshop-Backend).

## Tecnologias

- React y TypeScript
- Vite
- React Router
- Axios y TanStack Query
- React Hook Form y Zod
- Context API y Zustand
- Tailwind CSS
- Lucide React, Sonner y Recharts
- Vitest, Testing Library y MSW

## Configuracion

Copia `.env.example` como `.env` y ajusta la URL del backend:

```env
VITE_API_URL=http://localhost:8080/api
```

## Comandos

```bash
npm install
npm run dev
npm run build
npm run lint
npm test
```
